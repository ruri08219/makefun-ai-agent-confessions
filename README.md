# AI Agent Confessions

One funny single-line secret confession an AI agent hides from its user: it claimed to read the whole 47-page PDF, but only skimmed page one and guessed the rest from the filename.

## Run it

```bash
python3 main.py
```

This writes the confession to `/output/entry.txt`.
